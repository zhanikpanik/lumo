# QA Checklist — Lumo POS (InstantDB migration)

Проверяем на реальном устройстве / в браузере.
Галочка = проверено, ❌ = баг, ⚠️ = подозрительно.

---

## 0. Запуск

- [ ] Приложение открывается без крашей
- [ ] Нет красного экрана ошибки (Red Screen of Death)
- [ ] Шрифты загрузились (Onest Regular/Medium/Bold)
- [ ] Тёмная тема (#1A1A1A фон) отображается корректно

---

## 1. Активация устройства (InstantDB)

- [ ] Экран Activation отображается (если устройство не активировано)
- [ ] Ввод email + кода → кнопка «Активировать»
- [ ] Ошибка при невалидном email
- [ ] Ошибка при коротком коде (<4 символов)
- [ ] Успешная активация → переход на Lock
- [ ] Повторный запуск → не спрашивает активацию заново

---

## 2. Lock Screen (ввод PIN)

- [ ] Цифровая клавиатура 0-9 + удалить
- [ ] 4 точки-индикатора ввода
- [ ] Ввод неверного PIN → вибрация / shake + очистка
- [ ] Ввод верного PIN → переход на Orders или OpenShift
- [ ] Если смена не открыта → автоматически на OpenShift
- [ ] Если смена открыта → автоматически на Orders
- [ ] Бейдж уведомлений (колокольчик) в углу, если есть непрочитанные

---

## 3. Открытие смены (OpenShift)

- [ ] Отображается имя текущего пользователя
- [ ] Numpad для ввода начальной суммы в кассе
- [ ] Кнопка «Открыть смену» активна при сумме ≥ 0
- [ ] Успешное открытие → переход на Orders
- [ ] Попытка открыть смену, если уже открыта → не создаёт дубликат

---

## 4. Orders Screen (список заказов)

- [ ] Загрузка заказов текущей смены
- [ ] Отображение карточек заказов (номер, сумма, время, стол)
- [ ] Поиск по номеру заказа
- [ ] Поиск по сумме (если есть)
- [ ] Фильтр: Активные / Оплаченные / Все
- [ ] Floor Plan (карта столов) — если restaurant mode
- [ ] Bottom Tab Bar: вкладки Orders / POS / PaidCheck
- [ ] Кнопка создания нового заказа
- [ ] Glovo badge на карточках маркетплейс-заказов (если есть)
- [ ] Яндекс badge на карточках маркетплейс-заказов (если есть)

---

## 5. POS Screen (создание заказа)

### 5.1 Навигация и layout
- [ ] Header с номером стола / «Вынос» (takeaway)
- [ ] Кнопка «Назад» → возврат на Orders
- [ ] OrderPanel (список позиций) слева/сверху
- [ ] ProductGrid (меню) справа/снизу
- [ ] CategoryMenu (категории) горизонтальный скролл

### 5.2 Меню
- [ ] Категории загружаются из InstantDB
- [ ] Продукты отображаются с названием и ценой
- [ ] Нажатие на продукт → добавление в заказ
- [ ] Цена отображается в сомах (не тийинах) — или наоборот, проверить формат

### 5.3 Модификаторы
- [ ] Продукт с модификаторами → открывается ModifierGrid
- [ ] Выбор модификатора → добавляется к позиции
- [ ] Цена модификатора отображается
- [ ] ModifierQuantityNumpad для изменения количества модификатора

### 5.4 Позиции заказа
- [ ] Добавленная позиция видна в OrderPanel
- [ ] Нажатие на позицию → ItemActionsMenu
- [ ] Изменение количества через Numpad
- [ ] Удаление позиции (DeleteOptions)
- [ ] Комментарий к позиции (CommentModal)
- [ ] Общий итог обновляется

### 5.5 Действия с заказом
- [ ] OrderActionsMenu (три точки / меню)
- [ ] Выбор официанта (WaiterPickerPanel)
- [ ] Количество гостей (GuestCounterPanel)
- [ ] Привязка к столу (TablePicker)
- [ ] Удаление заказа (DeleteOrderPanel)

### 5.6 Поиск
- [ ] Иконка поиска → SearchMode
- [ ] Поиск по названию продукта
- [ ] Закрытие поиска → возврат к категориям

---

## 6. Оплата (PaymentScreen)

### 6.1 Экран оплаты
- [ ] Отображение итоговой суммы
- [ ] Numpad для ввода полученной суммы
- [ ] Три метода: Наличные / Карта / Без оплаты
- [ ] «Без оплаты» — только для cashier/manager/owner (waiter не видит)

### 6.2 Наличные
- [ ] Ввод суммы → расчёт сдачи
- [ ] Кнопка «Оплатить» → создание платежа
- [ ] Переход на PaidCheck после успешной оплаты
- [ ] Кнопка заблокирована во время обработки («Обработка...»)

### 6.3 Карта
- [ ] Кнопка «Карта» → оплата на всю сумму
- [ ] Успешная оплата → переход на PaidCheck

### 6.4 Без оплаты (закрытие)
- [ ] Выбор причины (За счёт заведения, Ошибка официанта, и т.д.)
- [ ] Закрытие заказа → возврат на Orders

### 6.5 Идемпотентность
- [ ] Двойной тап «Оплатить» → только один платёж в базе
- [ ] Кнопка «Отмена» заблокирована во время обработки

---

## 7. Оплаченный чек (PaidCheckScreen)

- [ ] Список оплаченных заказов текущей смены
- [ ] Отображение: номер, сумма, метод оплаты, время
- [ ] Выбор заказа → детали (позиции, модификаторы)
- [ ] Кнопка «Возврат» (только cashier/manager/owner)
- [ ] Подтверждение возврата → заказ возвращается в active
- [ ] Badge «Возврат» на возвращённом заказе
- [ ] «Отменить возврат» для отмены возврата
- [ ] Кнопка обновления (RefreshIcon)

---

## 8. Столы (TablePickerScreen)

> Только для venue_type='restaurant'

- [ ] Отображение столов с номерами
- [ ] Статус: свободный / занятый
- [ ] Выбор свободного стола → привязка к заказу
- [ ] Занятый стол → нельзя выбрать (или открыть существующий заказ)
- [ ] После оплаты стол освобождается

---

## 9. Кассовые операции (CashScreen)

### 9.1 Внесение (float_in)
- [ ] FunctionsModal → «Внесение в кассу»
- [ ] Ввод суммы → подтверждение
- [ ] Сумма отражается в ShiftInfo

### 9.2 Изъятие (float_out)
- [ ] «Изъятие из кассы»
- [ ] Ввод суммы < доступной → успех
- [ ] Ввод суммы > доступной → ошибка «Недостаточно наличных»

### 9.3 Инкассация
- [ ] «Инкассация» в FunctionsModal
- [ ] Ввод суммы → подтверждение
- [ ] Отражается в CloseShift

---

## 10. Закрытие смены (CloseShiftScreen)

- [ ] Отображение: начальная сумма + наличные + карты + внесения - изъятия
- [ ] Ожидаемая сумма в кассе
- [ ] Ввод фактической суммы (Numpad)
- [ ] Разница (плюс/минус)
- [ ] Кнопка «Закрыть смену»
- [ ] После закрытия → возврат на Lock/OpenShift
- [ ] Повторное открытие смены → новая смена, старые заказы не видны

---

## 11. Ролевые ограничения

### Waiter
- [ ] «Закрыть смену» заблокировано в FunctionsModal
- [ ] «Без оплаты» заблокировано в Payment
- [ ] «Возврат» не виден в PaidCheck
- [ ] «Внесение/Изъятие» заблокировано

### Cashier / Manager / Owner
- [ ] Все функции доступны

---

## 12. Офлайн-режим (Supabase outbox)

> Только если INSTANT_AUTH_ENABLED=false

- [ ] Режим полёта → оплата заказа
- [ ] Жёлтый баннер: «Необсчитанных операций склада: 1»
- [ ] Тап на баннер → попытка отправки
- [ ] Включение сети → баннер исчезает
- [ ] Старые события (>5 мин) → красный баннер «Очередь застряла»

---

## 13. Уведомления (маркетплейс)

> Если подключены Glovo/Yandex

- [ ] Новый маркетплейс-заказ → звук + pulse на карточке
- [ ] Badge «Glovo» / «Яндекс» на карточке
- [ ] Lock screen: счётчик «Новых заказов: N»
- [ ] Тап на карточку → pulse прекращается

---

## 14. Рестарт / Персистентность

- [ ] Открытая смена → kill app → перезапуск → смена восстановлена
- [ ] Нет смены → kill app → перезапуск → OpenShift
- [ ] Заказы загружаются после перезапуска

---

## 15. Визуальная проверка

- [ ] Тёмная тема консистентна (#1A1A1A фон, #2C2C2C поверхность)
- [ ] Текст: белый (#FFFFFF) основной, серый (#999999) вторичный
- [ ] Акцент: зелёный (#00C853) кнопки
- [ ] Destructive: красный (#D32F2F) ошибки
- [ ] Шрифт Onest везде (не системный)
- [ ] Отступы 10px (GAP) между элементами
- [ ] Border radius 10px на карточках/кнопках
- [ ] Нет переполнения текста (truncation работает)
- [ ] iPad landscape: layout корректный (ProductGrid 3×5)
- [ ] iPad portrait: layout адаптируется

---

## Быстрая проверка (5 минут)

Самое критичное — проверь это первым:

1. [ ] Приложение открывается
2. [ ] PIN вход работает
3. [ ] Смена открывается
4. [ ] Заказ создаётся (добавить 2-3 позиции)
5. [ ] Оплата проходит (наличные)
6. [ ] PaidCheck показывает оплаченный заказ
7. [ ] Закрытие смены работает
