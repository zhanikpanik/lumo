# Takeaway Mode (venue_type)

Режим для маленьких точек на вынос без зала и столов.
Один кодовая база, два режима работы — переключается на уровне venue.

## Включение

Установить `venue_type = 'takeaway'` для нужного venue:

```sql
UPDATE venues SET venue_type = 'takeaway' WHERE id = '<venue_id>';
```

По умолчанию все venue создаются как `'restaurant'`.

## Что меняется в UI


| Элемент                         | restaurant | takeaway                          |
| ------------------------------- | ---------- | --------------------------------- |
| Floor plan (столы)              | Показан    | Скрыт                             |
| Вкладка "Столы" в BottomTabBar  | Показана   | Скрыта                            |
| Кнопка "Назначить стол" в POS   | Показана   | Скрыта                            |
| Навигация в TablePicker         | Доступна   | Заблокирована                     |
| Фильтр заказов по умолчанию     | Все заказы | Открытые заказы (active)          |
| Сортировка "По столам"          | Доступна   | Скрыта                            |
| Метка "Быстрый чек" на карточке | Показана   | Скрыта (все заказы — quick check) |


## Флоу

```
Lock → Open Shift → Orders (список) → Новый заказ → POS → Оплата → Orders (список)
```

Все заказы создаются через `createQuickCheck()` — без стола, без зоны.
После оплаты навигация возвращается на экран заказов.

## Smoke-тест

1. Выставить `venue_type = 'takeaway'` в БД, перезагрузить приложение.
2. Убедиться, что floor plan и вкладка "Столы" не показываются.
3. Нажать "Новый заказ" — должен открыться POS без кнопки стола.
4. Добавить товар, оплатить — должен вернуться на список заказов.
5. Убедиться, что фильтр по умолчанию показывает "Открытые заказы".
6. Убедиться, что карточки заказов не показывают метку "Быстрый чек".
7. Вернуть `venue_type = 'restaurant'` — убедиться, что всё работает как раньше (столы, floor plan).
