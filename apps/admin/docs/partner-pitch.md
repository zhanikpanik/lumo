r_keeper — своя POS + админка для кофеен и ресторанов. Два приложения, одна база. Работает в Alto Coffee Bishkek. Переехали с Poster.

⚡ Живучесть

Выключили свет, пропал интернет — POS продолжает работать. Чеки, оплата, склад — всё пишется локально в SQLite на устройстве. Связь появилась — синхронизация автоматом.

POS собирается в APK под Android. Работает на чём угодно: касса-моноблок, дешёвый планшет, телефон официанта. Несколько устройств в одной смене — план зала обновляется в реальном времени, конфликтов нет.

Повторная отправка чека не задвоит склад. На сервере идемпотентные RPC: один чек = одно списание, сколько ни переотправляй.

🔍 Система сама ищет проблемы — 8 детекторов

Не менеджер следит за всем, а система показывает где проблема и что делать:

— Отрицательный остаток: «Молоко −3 литра на Баре»
— Без инвентаризации 30+ дней: «Зёрна не считали с 12 мая»
— Аномальная поставка: «85 000 сом — в 4 раза больше обычного»
— Мёртвое блюдо: «Сэндвич с тунцом — 0 заказов за 2 недели»
— Мёртвый ингредиент: «Кленовый сироп — на складе есть, расхода нет»
— Кассовый разрыв: «Расхождение 1 200 сом при закрытии»
— Официант с возвратами: «Айжан — 7 возвратов, норма 2»
— Подозрительный чек: «Чек #1432: блюд на 2 400, оплачено 300»

📦 Миграция с Poster

Не «ввести заново», а перенести данные. Экспорт Poster → XLSX → drag-and-drop в админку. Система сама распознаёт структуру колонок (русские и английские), конвертирует копейки в сомы. Что переносится: меню, техкарты, ингредиенты, склад, чеки, касса. База (меню/склад) уже готова, чеки и касса — добиваем.

🛵 Glovo + Яндекс Еда

Заказы из доставок падают напрямую в базу через webhook, минуя кассира. Склад списывается автоматом, чек виден в админке, смена учитывает. Разделение: видно какой заказ откуда пришёл.

Отменил Яндекс заказ до оплаты — RPC откатывает списание склада, защита от двойного отката.

Все таблицы marketplace закрыты RLS — публичный API наружу не торчит. Доступ только у Edge Function.

🏗 Из чего собрано

POS — React Native (Expo), Android APK
Админка — React 19 + TypeScript, браузер
База — PostgreSQL (Supabase), одна на оба приложения
Деплой — Vercel + Supabase, бесплатный тир

🏢 Multi-venue

База под несколько ресторанов от рождения. Кофейня А не видит данные кофейни Б. Новый ресторан подключается скриптом за 15 минут — свой Supabase + Vercel.
